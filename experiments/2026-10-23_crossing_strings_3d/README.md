# 3 次元：交差するひもの衝突

## 目的

空間を 3 次元にして、向きの違う 2 本の大域的ひもを衝突させ、ひもがつなぎ替わる（組み換え、intercommutation）かを調べる。

## 条件

- 方程式: φ″ + 2ℋφ′ − ∇²φ + a²λ(|φ|² − η²)φ = 0（輻射優勢期 a = τ/20、λ = η = 1）
- `src/bin/simulate3d.rs`: 7 点差分ラプラシアン、RK4（Δτ = 0.2Δx）、ディリクレ条件（境界の点を初期値に固定）、rayon で並列化
- 確認: z 方向を周期境界にした 512×512×4 格子で平行なひも（間隔 16、静止）を解き、2 次元の結果（`2026-10-21_global_string_flrw`）と比べる
- 本番: 256³ 格子、箱の一辺 32（Δx = 0.125）、τ = 20 → 36
  - ひも A: z 方向、(x, y) = (−4, 0) を通る、巻き数 +1、+x 方向へ速さ 0.5
  - ひも B: y 方向、(x, z) = (+4, 0) を通る、巻き数 +1、−x 方向へ速さ 0.5
  - 場は 2 本の積 φ = φ_A φ_B。動くひもはローレンツ収縮させたプロファイル（tanh）
- ひもの位置: x・y・z の 3 向きのプラケットで巻き数を数え、0 でないものの中心をひもの位置とする

## 結果

- 確認: 平行なひもの 3 次元の計算と 2 次元の計算の差は全時刻で最大 1.4e-14（丸め誤差）。対消滅の時刻も一致した。
- 2 本のひもは近づきながら中央で引き寄せられて曲がり（τ = 25 で中央の間隔 2.8）、τ = 25.75〜26.0 の間に組み換わった（τ = 0.25 ごとの出力 `crossing_fine` で判定）。
  - 組み換え前: ひも A は z = −16〜+16、ひも B は y = −16〜+16 にわたる。
  - 組み換え後: 「A の上半分と B の y > 0 の半分」「A の下半分と B の y < 0 の半分」がつながった 2 本になる。
- 組み換えの後、2 本のひもは折れ曲がりがほどけるように中央から離れ、中央には円形の放射が広がる。
- ひもの長さ（巻き数をもつプラケットの数 × Δx）は 64 から 91 まで伸びた後、組み換えで減り、τ = 28 以降は 80 で一定になる。この長さの数え方は斜めの線を各座標方向の長さの和で数えるので、斜めにまっすぐ張ったひもでは実際の長さより長く出る。80 は、境界に固定された両端を結ぶ折れ線のない 2 本（実際の長さは各 24）にあたる。

## 図

- `figures/reconnection_summary.png`、`figures/reconnection.gif`（`animate.py`）: ひもの位置を、つながっている塊ごとに、どの壁で終わっているかで色分けした。青 = ひも A（z = ±16）、橙 = ひも B（y = ±16）、緑 = z = +16 と y = +16 をつなぐひも、赤 = z = −16 と y = −16 をつなぐひも。x 軸方向から見た図（右端）では、組み換え前は「＋」、組み換え後は 2 つの「L 字」に見える。

## 注意

- ディリクレ条件のため、ひもの両端は箱の壁に固定されている。壁の影響は光速で中心に伝わり、壁から中心まで 16 なので、中心で起きた組み換え（τ ≈ 26）には影響しないが、組み換え後にひもがまっすぐ張る様子は壁の固定に引っ張られている。
- 格子は 1 種類（Δx = 0.125）だけで、解像度を変えた確認はしていない。
