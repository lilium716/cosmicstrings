# RK4 でのエネルギー保存

## 目的

`src/bin/simulate.rs` の RK4 による時間発展で、エネルギーが保存するかを確かめる。膨張があると摩擦項 2ℋφ′ のためにエネルギーは保存しないので、膨張なしで調べる。

## 条件

- `2026-10-21_global_string_flrw` と同じ設定（512² 格子、Δx = 0.125、ディリクレ条件、初期間隔 16、τ = 20 → 60）で、膨張なし（a = 1、ℋ = 0）
- 時間刻み Δτ/Δx = 0.4, 0.2, 0.1, 0.05
- エネルギー E = Δx² [ Σ_点 (|π|² + (λ/2)(|φ|² − η²)²) + Σ_隣り合う点の組 |φ_b − φ_a|²/Δx² ]。勾配の項を 5 点差分ラプラシアンと対になる形で書いているので、空間を離散化した方程式の厳密な保存量である。したがって残る変化は時間積分（RK4）の誤差だけになる

## 結果

| Δτ/Δx | 最大の相対変化 \|E − E_i\|/E_i | 前の行との比 |
| --- | --- | --- |
| 0.4 | 6.1e-7 | |
| 0.2 | 2.4e-8 | 25（次数 4.7） |
| 0.1 | 1.6e-9 | 15（次数 3.95） |
| 0.05 | 1.0e-10 | 16（次数 3.98） |

- エネルギーは保存している。通常の設定（Δτ/Δx = 0.2）での変化は 40 の時間の間に相対 2e-8。
- 時間刻みを半分にすると変化は約 1/16 になり、RK4 の 4 次精度どおりに減る。
- 変化が最も大きく増えるのは対消滅の時（τ ≈ 34〜36）で、場が速く変化するためである。膨張なしでは対消滅は τ = 32〜36 の間に起きた。
