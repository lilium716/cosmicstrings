# 大域的ひも（FLRW 時空）

## 目的

巻き数が逆向きの大域的ひも 2 本（2 次元断面では渦と反渦）を静止した状態で置き、輻射優勢期の FLRW 時空で対消滅するまでを差分法で解く。

## 条件

- 方程式: φ″ + 2ℋφ′ − ∇²φ + a²λ(|φ|² − η²)φ = 0、a = τ/τ_i
- η = 1、λ = 1、初期プロファイル tanh(r/w)（w = 2/(√(2λ)η) ≈ 1.41）
- 格子 513²（両端を含む）、箱の一辺 64、Δx = 0.125、Δτ = 0.2Δx
- 5 点差分ラプラシアン、RK4、ディリクレ条件（境界を初期値に固定）
- τ = 20 → 60（a = 1 → 3）、初期間隔 16、初速 0
- ひもの中心は格子点に乗らないよう (1/24, 1/24) ずらしている

## 結果

- τ = 38 から 40 の間に対消滅した（巻き数で数えたひもが 0 本になる）。
- その後、|φ| の最小値は 1 近くに戻り、放射が円形に広がる。
- ディリクレ条件のため、対消滅後も境界に固定した初期の位相の模様が残り、場は一様な真空には戻らない。
